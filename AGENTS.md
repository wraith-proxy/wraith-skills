# wraith-skills

wraith is a plugin of skills and agents for data and infrastructure
engineering on GCP.
It serves Claude Code and GitHub Copilot from one repository.

## Commands

- `uvx --python 3.12 pre-commit run --all-files` (lint, copilot check, privacy scan,
  file types and plugin checks, all from wraith-tooling)
- `uvx --from git+https://github.com/wraith-proxy/wraith-tooling@b1b679614c2a4601363208459461daf036200559 wraith-build-copilot`
- `claude plugin validate --strict .`
- `claude plugin eval .`

## Rules

- Portable skill frontmatter only: `name`, `description`, `license`,
  `compatibility`, `metadata`, `allowed-tools`.
- The plugin ships only Markdown, text, JSON, YAML and images
  (`wraith-file-types` enforces it). Tooling lives in
  wraith-proxy/wraith-tooling.
- No em dash (U+2014) in skills, agents, hooks, evals, README or AGENTS.md.
- Never edit `com.github.copilot/agents/`; it is generated by
  `wraith-build-copilot`.
- Commit format `👻 <type>/WSK-<5 digits>: <summary>`, types `feature`,
  `fix`, `bug`, `break` (these four release) and `docs`, `chore`, `ci`,
  `test`, `refactor` (no release). No attribution trailers, never `--no-verify`.
  PR titles use the same format: the squash subject decides the release,
  and CI rejects a title that does not match.
- No private data: personal emails, private IPs, internal hostnames, home
  paths, employer or client names, credentials.
