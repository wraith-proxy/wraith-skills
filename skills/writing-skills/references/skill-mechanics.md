# Skill mechanics

The skill-specific branch of [`writing-for-agents`](../SKILL.md): what changes when the document is a skill (frontmatter and its invocation). Everything else about writing it is the universal reference in `SKILL.md`.

## Invocation

wraith skills use only portable frontmatter: name, description, license, compatibility, metadata, allowed-tools. A skill meant only for explicit use says so in its description: 'Use only when the user asks to ...'.
